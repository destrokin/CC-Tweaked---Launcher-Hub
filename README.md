This script has many features for QOL and are listed below
  - Selection GUI
  - Settings Menu
  - Crash Logs
  - Automatic Lua Detection
  - Floppy Disk Manager

Whats so special?

Do you have multiple Lua scripts on one computer and hate having to stop the script in order to swap to another? Well Look no further. This script lets you setup a redstone relay for sending you back to the main menu just by pressing a button. Long gone are the days of Turn it off and back on again and welcome the new age of Click and forget.
  
What are the settings?

   There are 2 things in settings. Relay, and Monitors.
     - Relay list all current relays on a network and stores them in a file called "rsguic_data.txt" Which is also tied to another program ive uploaded called "RSGUI Control Script".
       In this list you can click on a relay and either set it as the reset button for bringing you back to the main menu of the Lua Launcher, or you can rename the relays for customization reasons.
     - Monitors list all current monitors on a network and does the same thing as relay. It lets you set the Main Monitor for the Lua Launcher and even rename monitors aswell.

Why crash logs?
  Well have you ever just had a script close on you so you have to run over the the computer and look at the output for what error it gave. Well this stores that for later use if you ever need to re open the error and see what went wrong. Also instead of your scripts just "Ending" your who pc. This will instead make it so it keeps the program running by running the Launcher as main and all other scripts inside a shell. Basically a minecraft VM

What is Disk Manager?
- simply insert a floppy disk and you can easily copy all code to it with a click of a button
- or you can copy all code and text files from the floppy disk onto your computer

Its just that simple, Run the program and let it do all the work. Select your script on screen and hit run.

I recommend a size of 5x3 also you should rename the script to "startup" so it automatically launches when your computer turns on or a server restarts.

Thats pretty much it. There are settings you can change in the code like Gui Scale but its already set to its smallest by default. Also gui scale increases by .50 so starting at .50 - 1 - 1.50 and so on.
